# Andres Alcantar — Portfolio

Personal portfolio and engineering case studies. Built with vanilla HTML, CSS, and JavaScript — no frameworks, no build step, deploys directly via GitHub Pages.

## Projects

### Equator — Full-Stack Mobile Application
Android inventory management app built with Kotlin and Firebase. Refactored from a legacy SQLite architecture to a cloud-integrated MVVM system with real-time synchronization, B-Tree indexing, custom Binary Search and Merge Sort implementations, and Firebase Authentication.

[View Case Study →](https://isladr3.github.io/equator.html)

### Secure Web Application Refactoring
Java/Spring Boot application hardened against the OWASP Top 10. Remediated SQL injection and XSS vulnerabilities, containerized services with Docker for Kubernetes deployment, and implemented automated vulnerability scanning with SSL certificate management.

[View on GitHub →](https://github.com/isladr3/travlr)

### 3D Platformer Prototype
Unreal Engine 5 project featuring modular gameplay systems, enemy AI via Behavior Trees, and optimized event-driven C++ logic maintaining a stable 60fps under load.

[View on GitHub →](https://github.com/isladr3/Offering_RP)

## Running Locally

This is a static site — no build step required.

```bash
git clone https://github.com/isladr3/isladr3.github.io
cd isladr3.github.io
# Open index.html in your browser, or serve with any static file server:
npx serve .
```
